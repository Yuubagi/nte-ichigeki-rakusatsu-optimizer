# 一撃落札の展示収益 最大化ツール

「一撃落札」の展示で、盤面にアイテムを並べたときの**展示収益の合計が最大になる配置**を求める、ブラウザだけで動くツールです。

[ツールを開く](https://yuubagi.github.io/nte-ichigeki-rakusatsu-optimizer/)

> NTE(Neverness to Everness)の非公式ファンツールです。ゲームの運営会社・開発元とは関係ありません。

## 特徴

- インストールもサーバーも不要です。`index.html` だけで動きます(画像は `img/` にありますが、なくても動作は変わりません)。
- アイテム(展示収益・縦・横)と所持数を入力すると、最良の配置を盤面に表示します。盤面は縦8×横15、配置できる個数は最大99個で固定です。
- 所持数を入力したアイテムは、その数を超えて配置しません。
- アイテムは、回転しない長方形として扱います。
- 入力した内容は、ブラウザの中にだけ保存されます。外部への送信はありません。
- アイテムの表は、表計算ソフトからの貼り付けと、書き出しに対応しています。

## 使い方

1. アイテムの表に、展示収益・縦・横を入力します。マス数と展示効率は、自動で計算されます。
2. **所持数を入力します。** 空欄は無制限として扱うため、実際の所持数を入れないと、現実的でない結果になります。
3. 表の右上の「計算する」を押します。計算は最大10秒で、計算中も、そこまでで最良の配置が表示されます。

「橙品質の全アイテムを追加（39種）」を押すと、展示収益が確認できる橙品質の全アイテムを追加できます。登録済みの行や所持数は変更せず、未登録分だけを所持数0で追加します。追加後に持っている数を入力してください。データは[NTE一撃落札DB](https://ddangcalc.com/ja/items)の一覧と各詳細ページを2026年11月13日に確認したものです。

表をまとめて入力したいときは、ページ下の「表を一括で貼り付ける・書き出す」を使います。入力の形式は、ページ内に説明があります。

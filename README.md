# 一撃落札の展示収益 最大化ツール

「一撃落札」の展示で、盤面にアイテムを並べたときの**展示収益の合計が最大になる配置**を求める、ブラウザだけで動くツールです。

[ツールを開く](https://yuubagi.github.io/nte-ichigeki-rakusatsu-optimizer/)

> NTE(Neverness to Everness)の非公式ファンツールです。ゲームの運営会社・開発元とは関係ありません。

## 特徴

- インストールもサーバーも不要です。`index.html` だけで動きます(画像は `img/` にありますが、なくても動作は変わりません)。
- アイテム(展示収益・縦・横)と所持数を入力すると、最良の配置を盤面に表示します。盤面は縦8×横15、配置できる個数は最大99個で固定です。
- 所持数を入力したアイテムは、その数を超えて配置しません。
- アイテムは、回転しない長方形として扱います。
- 入力した内容は、ブラウザの中にだけ保存されます。外部への送信はありません。
- アイテムの表は、表計算ソフトからの貼り付けと、書き出しに対応しています。

## 使い方

1. 「アイテム一覧」で持っているアイテムを探し、「所持アイテムに追加」を押します。橙品質39種類を画像・展示収益・サイズ付きで確認できます。名前で検索できます。
2. 「所持アイテム」タブを開き、実際の所持数を入力します。一覧の追加ボタンを押すたびに所持数が1個ずつ増えるため、持っている数だけ押して指定することもできます。
3. 「計算する」を押します。所持アイテムを対象に、最大10秒で配置を計算します。

同じアイテムの追加ボタンを繰り返し押すと、同じ行の所持数が増えます。現在の所持数は一覧にも表示します。所持アイテムから削除すると、一覧から再追加できます。独自アイテムの追加と、表計算ソフトからの一括貼り付け・書き出しにも対応しています。所持数の空欄は従来どおり無制限として扱います。

保存済みの所持数・編集した値・独自アイテムは引き継ぎます。旧形式の未編集で所持数0のプリセット行は、アイテム一覧にまとめます。

データは[NTE一撃落札DB](https://ddangcalc.com/ja/items)の一覧と各詳細ページを2026年11月13日に確認したものです。
